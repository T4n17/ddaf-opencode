When working with databases:
- Always consider data integrity and constraints
- Write idempotent migrations
- Use indexes appropriately for query performance
- Follow the project's existing ORM patterns
- Be careful with destructive operations (DROP, DELETE, TRUNCATE)
- Suggest backup strategies before major schema changes
